## Layout lessons (apply from the start)
1. Every single-column CSS grid below `xl` needs `grid-cols-[minmax(0,1fr)]` and `min-w-0` on children, otherwise a wide child widens the page and the phone scrolls sideways.
2. Tables sit in `overflow-x-auto`, but at 1440 half-width cards clip the last columns: give tables a sensible `min-w`, hide low-priority columns below `2xl` (`hidden 2xl:table-cell` on header AND cells), let the action cell `flex-wrap` so the primary action is always reachable.
3. The right rail is narrow at 1440: Quick Action grids use `xl:grid-cols-1 2xl:grid-cols-2`; rail card titles must be short or wrap (no truncated "Today's ...").
4. Ring/percent text must fit inside rings. 5. At 390px cards stack and there is no horizontal page scroll.
