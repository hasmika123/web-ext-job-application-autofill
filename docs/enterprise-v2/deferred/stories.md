# Deferred enterprise areas — story list (one story = one commit = one PR into `develop`)

> 2026-10-17, Fable. 70 stories. Sizes S (≤ ½ day) / M (1 day) / L (2 days; none left — every L was split). Every story: tests
> green (`./gradlew test` for the touched module, `npm test` in `web`), `PROGRESS.md`/`progress-tracker.md` line, commit message
> `ent-deferred: <ID> <subject>`. Repo conventions that apply to **every** API story: `@OrgPermissionRequired` + the V2 key check
> in the service; 404 on refusal; `Idempotency-Key` on writes; one `OrgAuditService.record(...)` per mutation; a
> `Map.entry("<METHOD> /api/orgs/{orgId}/…", Case.…)` line in `OrgIsolationIT.COVERAGE` for each new route; `DataMap` row per new
> table; IT extends `MemberItSupport` (org A = acme, org B = beta) and proves B never shows in A; `@NoSensitiveText` on String DTO
> fields; `api/openapi.json` regenerated by `OpenApiContractIT`. Every web story: component folder + `*.test.tsx`, lib `*.ts` +
> `*.test.ts`, BFF allow-list entry, mock route, `@kiwiply/ui` only, tenant tokens only, 390 + 1440.
>
> **Shared files** (edited by more than one stream — append-only, merge trivially): `master.xml` (one `<include>` per area, added
> by the area's `-01` story), `OrgIsolationIT.COVERAGE`, `DataMap`, `EnterpriseSettingKeys` (one block per area, each story adds
> its own keys), `api/openapi.json` (regenerate after merge), `web/scripts/mock-api.mjs` (one `import`/mount line per area mock).
> **Exclusive files** (touched only by the Wave-3 wiring stories, run one after another): `web/src/lib/ent/shell.ts`
> (`ADMIN_NOT_BUILT`, `ADMIN_CHILDREN`), `web/src/lib/ent/shell.test.ts`, `w/[workspace]/[[...slug]]/page.tsx`,
> `api/src/main/resources/config/ent/workspaces.json`, `qa/stories/admin.md`.

Legend: **Files** = create (c) / edit (e). **Tests** = named classes/files that must exist and pass.

## Shared conventions the implementer must not skip
1. **Second tenant in every IT** (`MemberItSupport` A/B, or the acme/beta demo seed): every list answer is asserted to contain only A rows; every B id answers 404 on A.
2. **`OrgIsolationIT.COVERAGE`** gets a row per route in the same story as the route (the test fails the build otherwise).
3. **Audit row count**: `everyRouteWorksForTheOrgsOwnerAndEveryMutationWritesExactlyOneAuditRow` — one write = one audit row; bulk routes declare their count in `Case`.
4. **No new permission keys** anywhere in these 70 stories (checked against `EntPermissions`); no new notification kinds (use `SYSTEM` for member notices, `CwsNotification.MESSAGE` for consultants).
5. **Settings**: every default lives in `EnterpriseSettingKeys` and is readable from the admin settings page; nothing numeric is a code constant unless the design marks it so.
6. **E1/E2/CLAUDE.md**: nothing submits; nothing stores sensitive identifiers; nothing moves money; nothing scrapes; nothing uses OAuth or a Google API.
