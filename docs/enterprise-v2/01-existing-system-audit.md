## 2. Existing Subscription Audit

### 2.1 Entitlement source of truth
- `api/service/EntitlementService` (`@Service`, read-only tx):
  - `isProFor(status, currentPeriodEnd, now)` — pure: `active|trialing` → Pro; `past_due|canceled` → Pro only while `currentPeriodEnd > now`; anything else → Free.
  - `isPro(login)`, `isCurrentUserPro()`, `plan(login)` → `PlanDTO(plan, status, currentPeriodEnd, cancelAtPeriodEnd, billingEnabled, hasCustomer)`, `requirePro(login)` → `ProRequiredException(CODE_PRO_REQUIRED)` → **402** via `ExceptionTranslator`. Second code: `CODE_RESUME_LIMIT`.
  - Keyed by **login only**. No org, no feature key, no beneficiary.
- Callers of `isPro`/`requirePro` (grep): `AiBudgetService`, `AiDraftService`, `ResumeAiService`, `FieldCacheSyncService`, `JobFitService`, `JobMatchService`, `ResumeMatchService`, `ResumeTailorService`.
- The plan travels on `GET /api/profile/version` (`ProfileResource.getProfileVersion` → `entitlementService.currentUserPlan().plan()`), consumed by the extension (`sync.js checkAndPull`). No JWT claim (locked).

### 2.2 The `subscription` mirror
- `domain/Subscription`: `user` (FK), `stripeCustomerId`, `stripeSubscriptionId`, `plan` (`PLAN_FREE`/`PLAN_PRO` strings, column `varchar(20)` default FREE), `status` (Stripe status string, default `none`), `priceId`, `currentPeriodEnd`, `cancelAtPeriodEnd`, `lastEventAt`. Changelog `20260921000000_subscription.xml` also creates `stripe_event` (id, type, received_at, processed_at, status, error) for idempotent webhook replay.
- **AUTOPILOT is not in the data** at this commit: no plan constant, no price property. `StripeProperties` holds `priceMonthly`, `price3mo`, `amountMonthly=19.99`, `amount3mo=49.99`, success/cancel/portal URLs defaulting to `https://kiwiply.com/…`, `automaticTax=false`, `managedPayments`.

### 2.3 `StripeGateway` and webhook-only writes
- `service/billing/StripeGateway` interface: `isEnabled()`, `createCustomer(email, login, userId)`, `createCheckoutSession(customerId, priceId, userId, successUrl, cancelUrl)`, `hasLiveSubscription(customerId)`, `cancelSubscription(id)`, `createPortalSession(customerId, returnUrl)`, `constructEvent(payload, sig)`. Impl `StripeGatewayImpl`; **billing disabled when the key is blank** (`isEnabled()`), honoured by `EntitlementService.plan()`.
- `BillingWebhookService.handle(StripeWebhookEvent)` → `Outcome`; dedupes by `stripe_event.id`; handles `checkout.session.completed` (bind customer), `customer.subscription.{created,updated,deleted}` (upsert mirror), `invoice.paid` (status active), `invoice.payment_failed`; handler failure leaves a record and returns 500 so Stripe retries. **Only this service writes `subscription`.** `BillingResource`: `GET /api/billing/me`, `POST /checkout`, `POST /portal`; `BillingWebhookResource`: `POST /api/billing/webhook` (permitAll, signature-verified).
- **Gaps for V2:** no org customer, no subscription items/quantities, no invoices mirror, no proration API, no coupons, no refunds method, no test-clock hooks. The interface must grow (`createOrgCustomer`, `createSubscriptionWithItems`, `setItemQuantity(proration)`, `previewUpcomingInvoice`, `listInvoices`, `createCoupon`, `refund`).

### 2.4 Plans, AI budgets, `isPro`, 402
- Plans in code today: **FREE, PRO** (strings). Locked product tiers Free/Pro/Autopilot exist in CLAUDE.md/ROADMAP; Autopilot is not implemented.
- AI budgets: `AiPolicy.proMonthlyBudgetUsd` / `pro3moBudgetUsd` (→ micros), `softCapPercent`, per-task models, disabled tasks; `AiBudgetService.decide(login, task)` uses `AiQuotaOverride.monthlyBudgetCents` (admin override outranks the plan gate — locked), monthly window from month start. Costs recorded per call in `ai_call.cost_micros`. Registry keys `ai.daily_cost_cap_cents`, `ai.monthly_cost_cap_cents`, `ai.free_parse_reserved_pct` (platform-wide caps).
- 402: `ProRequiredException` → ProblemDetail with `code: PRO_REQUIRED` (or `RESUME_LIMIT`), consumed by web and extension.

### 2.5 Phase 18 DB catalog
- **Not present** at this commit. Design only: `docs/design/admin/catalog-margin-entitlements.md` (tables `product`, `product_price` immutable rows with `stripe_price_id`, `product_entitlement` feature keys with limits, `bundle_item`, `MarginCalculator`, 422 `MARGIN_BELOW_FLOOR`) and `docs/design/pay/catalog-entitlements-engine.md`. Roadmap stories A3.1–A3.7 are `not_started`. Settings keys `catalog.margin_floor_*`, `catalog.stripe.*` already exist in `AdminSettingKeys` (A5.1).
- Consequence: Enterprise V2's feature catalog **is** the Phase 18 catalog, extended with feature dependencies, presets, contracts and usage allowances — it must not be a second catalog.

### 2.6 Org billing prior art
- `organization.stripe_customer_id`, `setup_fee_paid_at`, `billing_email`, `OrgStatus` (DRAFT → PENDING_SETUP_FEE → ACTIVE → PAST_DUE/SUSPENDED → CLOSED) exist. `docs/design/org/billing.md` designs one Stripe customer per org, one monthly `send_invoice` subscription with one item per org price and quantity = assignments, add = prorate, remove = period end, dunning from Stripe. Branch A adds `OrgBillingResource` (`GET /billing`, `POST /activate` dev-only when Stripe is off, `dossier.orgs.dev-activate`). None of the Stripe calls exist yet.

**Constraints this imposes (carried into 02 topic 2 and ADR-002):**
1. Any new public hostname — `acme.kiwiply.com` or `careers.acme.com` — needs a certificate and a route in a Caddyfile this repo does not own. That is a one-time, hand-applied edge change (an `on_demand_tls { ask … }` global + a catch-all `https://` block → `dossier-web:3000`) and must be coordinated with BeeCompete.
2. `*.kiwiply.com` wildcard certs need DNS-01 (Cloudflare plugin + API token) in the edge image; per-hostname on-demand certs avoid that at the cost of Let's Encrypt's 50 certs / registered domain / week.
3. Customers who orange-cloud their CNAME break HTTP-01; instructions must say DNS-only or use the CNAME-to-`edge.kiwiply.com` pattern with on-demand TLS.
4. The app is single-origin everywhere a URL is built (mail, Stripe, OG, extension). Tenant-aware URL building is a cross-cutting change.
5. One instance: tenant caches may be in-process, but nothing may assume cross-request memory beyond a TTL cache.

## 4. Existing org model (merged, verified)

### 4.3 Enforcement
- `@OrgPermissionRequired(OrgPermission...)` on handlers under `/api/orgs/{orgId}/…`; `OrgPermissionInterceptor.preHandle` parses `{orgId}` from the path (never header/body), calls `OrgAccessService.requireAll`, stores `OrgMembership` in the request attribute; handlers without the annotation or `@OrgUnscoped` are refused with 404 and an ERROR log. Endpoints today: `POST /api/orgs` (unscoped), `GET /mine` (unscoped), `GET/PATCH /{orgId}`, `POST /{orgId}/close`, groups CRUD.
- `OrgIsolationIT` asserts: every org route is in the coverage registry; every route carries an annotation; no outsider reaches org A; org B's owner cannot reach org A rows with his own id; platform admin lists no orgs; every mutation writes exactly one audit row; every org repository method is exercised across tenants; share scopes gate staff reads; FULL sharing reaches only the named marketer.

### 4.4 Flag and public config
- `OrgsEnabledFilter` (404 problem JSON) + interceptor second wall; `OrgFeatureFlag`; `PublicConfigResource` → `{orgs, demo}`; web `getPublicConfig()` fails closed.

## 6. Cross-cutting findings (short)

- **Identity model supports multiple memberships per global user** (`org_member.user_id` + `active_user_key` one live row per org). Requirement §9 "multiple organization memberships per global identity" is satisfied by the schema.
- **Tenant-scoped repositories** already follow "orgId first" (`findByOrgIdAndUserIdAndStatusIn`, `organizationRepository.findByOrgId`), and `OrgIsolationIT` sweeps every repository method. New repositories must follow the same contract.
- **Audit**: `OrgAuditEvent` keys actors by login string (survives erasure). It lacks `hostname`/`tenant kind` and a `beneficiary` column — additive.
- **Notifications** already dedupe and group; enterprise kinds are new strings.
- **Settings registry** gives the "everything admin-configured" rule a home: every enterprise limit, cap, default and flag is a `SettingDefinitions` key; per-org overrides need an `org_setting` table (Phase 2).
- **Demo**: `DemoOrgSeeder` + `web/scripts/fixtures/demo-org.json` seed "Demo Bootcamp" (`demo-org` owner). Enterprise fixtures should add `acme` (CONSULTANCY) and `beta` for the F scenario.
- **Resume access `Via.ORG`** already models "the org sees this because of consent"; `ResumeViewEvent.KIND_ORG` audits reads.
