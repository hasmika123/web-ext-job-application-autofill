# Resume templates — stories (build sequence for Sonnet)

Design: `TEMPLATES-DESIGN.md` (§ references below point there). Decisions: `decisions-for-user.md`
(all decided — do not ask). Branch: `resume-templates` (off `version2`); **one story = one commit**,
message `resume-templates: <subject>`, ending with
`Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Never `git add -A`; add the named paths.
Green before each commit: `npm test -w packages/ui`, `npm test -w web` (tsc + eslint + vitest),
`cd api && ./gradlew test` when a Java file changed. No version bump (no extension change).

Conventions every template story follows ("the template checklist"):

1. `packages/ui/src/resume/templates/<id>.tsx` — `export const <id>: TemplateDefinition` with
   `meta { id, name, description, category, atsNote, capabilities, thumb: "<id>.png", defaults }` and a
   pure `Render`. Header comment = the §6 identity paragraph.
2. `packages/ui/styles/resume.css` — one block between `/* == tpl:<id> == */` and `/* == /tpl:<id> == */`
   holding every `.rz-tpl-<id>` rule from §6 (the compliance test reads the block by these markers).
3. `packages/ui/src/resume/registry.ts` — import + entry in `TEMPLATES` in §0 order.
4. `packages/ui/src/resume/__fixtures__/template-defaults.json` **and**
   `api/src/test/resources/resume-doc/template-defaults.json` — the id with its `defaults` (byte-identical files).
5. `api/.../service/resume/TemplateThemeDefaults.java` `BUILT_IN` — the same defaults;
   `api/.../service/ResumeDocService.KNOWN_TEMPLATE_IDS` — the id.
6. `web/src/components/app-v3/resume-builder/list/templateThumbs.ts` — `import <id> from "@kiwiply/ui/resume/thumbs/<id>.png"` + map entry.
7. `packages/ui/src/resume/thumbs/<id>.png` — generated by `npm run thumbs:templates -w web -- --only <id>` and committed.
8. `packages/ui/src/resume/templates/<id>.test.tsx` — §12.2 (snapshots × full-v2, sparse, caps-doc,
   sample; class/style/table rule; profile declaration; ATS compliance when `ats`; layout wiring;
   project dates). Snapshot files under `templates/__snapshots__/`.
9. `registry.test.ts` — the "ten production templates" assertion grows by this id (keep the final
   list in a const `PRODUCTION_IDS` so each story adds one line).
10. Settings defaults (`ResumeBuilderSettingKeys` `TEMPLATES_ENABLED` JSON and web
    `DEFAULT_BUILDER_CONFIG.templates.enabled`) — append the id (both sides, same order).

grows predictably) → T15 → T16. T6–T14 each need a browser once for the thumbnail

commit the template without the PNG, mark the story "thumb pending" in the commit body and the
`thumbs.test.ts` will fail until the PNG is generated — generate all pending ones in one go and
commit them as `resume-templates: thumbnails for <ids>` before T15.
