Settings

Optional. Without a key, resumes are parsed with a built-in heuristic — rougher, but everything is editable. The same key also drafts answers to open-ended application questions ("Why this role?"), which are cached and reused when the same question appears again. Your key is stored locally on this device only and is sent only to api.anthropic.com.

Automation

Off by default. When on, Dossier clicks the page's Next or Continue button after you fill a step, so multi-step flows (like Workday) move forward on their own. It detects forward-navigation buttons only and never clicks Submit, Apply, or Finish — you always send the application yourself. You can also flip this from the popup.

On by default. On Workday's Work Experience step, Dossier adds enough entry blocks to hold all the roles in the selected resume before filling them.

Field rules

The map from page fields to your data lives in a versioned ruleset, separate from the extension. When an ATS (e.g. Workday) changes its markup, an updated ruleset fixes filling without a new extension version. Point this at a hosted ruleset JSON (same shape as the bundled one) and check for updates.
