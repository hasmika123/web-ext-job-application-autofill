Data Platform Engineer

Remote, United States

Northwind Labs is hiring a Data Platform Engineer to build and run the platform behind our analytics products: pipelines, warehouses and the tools other teams use every day.

What you'll do

  • Design reliable data pipelines in Python and SQL and orchestrate them with Airflow
  • Run the platform on AWS with Kubernetes and Terraform, and own its monitoring and on-call
  • Work closely with analytics and product teams, and improve CI/CD for data releases

What you'll bring

  • 5+ years building data or platform infrastructure
  • Strong Python and SQL; experience with AWS, Kubernetes, Terraform and Airflow
  • Nice to have: dbt, Snowflake, GraphQL, Spark
